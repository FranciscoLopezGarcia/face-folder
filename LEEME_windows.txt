FACE FOLDER PARA WINDOWS - GUIA FACIL
=====================================

No necesitas saber programar ni instalar Python.

1. Haz clic derecho sobre el archivo ZIP que descargaste.
2. Elige "Extraer todo..." y luego "Extraer".
3. Abre la carpeta extraida.
4. Haz doble clic en "Empezar.bat".
5. Arrastra la carpeta con tus fotos a la ventana negra y presiona Enter.
6. Si quieres guardar el resultado en otro lugar, arrastra esa carpeta cuando
   te lo pregunte. Si no, simplemente presiona Enter.
7. Espera hasta que diga "Terminado".

La primera vez necesita internet y puede tardar varios minutos porque prepara
Python, las dependencias y el modelo facial. Las siguientes veces son mas rapidas.

Las fotos originales NUNCA se borran, mueven ni modifican. Face Folder crea
copias dentro de resultado, resultado_2, etc.

AVISO: el modelo buffalo_l de InsightFace es solo para investigacion no
comercial. Para trabajo profesional o comercial se necesita una licencia
apropiada o un modelo diferente.

Si algo falla, guarda una captura de TODA la ventana negra.
